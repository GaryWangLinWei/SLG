# 数字模板匹配说明

## 为什么用模板匹配？

Tesseract OCR 对于游戏中半透明叠加在地图背景上的数字识别效果很差。
模板匹配针对固定字体的数字，准确率可达 99.9%，而且速度极快。

## 如何制作模板？

1. 截取 10 张距离截图，每张截图里有一个干净的数字（0-9）
   - 使用游戏内的距离显示区域
   - 尽量截不同背景下的，选最清晰的
   - 每张只包含一个数字，尽量贴近数字边缘

2. 命名为 `digit_0.png`, `digit_1.png`, ..., `digit_9.png`

3. 放到这个目录下

4. 重启后端服务，会自动加载

## 模板尺寸建议

每个数字模板建议尺寸：约 15x25 像素（根据实际游戏字体调整）

## 示例

如果距离显示 "120 公里"，把 1、2、0 分别截成三张独立的小图，
分别命名为 digit_1.png、digit_2.png、digit_0.png。

## 调试

第一次使用时，控制台会输出 `[DigitMatcher] 已加载 N 个数字模板`
如果 N=0，说明模板没有正确放置。
